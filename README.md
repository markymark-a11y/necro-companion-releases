# NecroCompanion

A Windows overlay for **Diablo II: Resurrected** that coaches a build while you play: what to
do next, where to spend skill and stat points, which runes, gems and items to keep, and what
to farm. It reads only what's on your screen (like a stream recorder) and never touches the
game: no memory reading, no input, no game files.

## Install

1. Open the [latest release](../../releases/latest) and download
   `NecroCompanion_<version>_x64-setup.exe`.
2. Run it. Windows may say "Windows protected your PC" because the installer isn't signed
   with a paid certificate: click **More info → Run anyway**.
3. Start the game in **Windowed** or **Windowed (Borderless)** mode, then NecroCompanion. A
   short setup walks you through the rest.

Updates install from inside the app ("Install and restart").

This repository only holds the installers; the source is private.
